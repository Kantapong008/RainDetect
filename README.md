# Physical Computing Project 2026 - IT KMITL
## RainDetect
### **1. รายละเอียดและจุดประสงค์ของโครงงาน** <br />
RainDetect เป็นโครงงานระบบติดตามสภาพแวดล้อมและประเมินความเสี่ยงที่อาจเกิดฝน โดยใช้ Arduino UNO R4 ร่วมกับเซนเซอร์ BME680 และจอ LCD พร้อมเว็บไซต์สำหรับแสดงข้อมูลสภาพแวดล้อมและผลการประเมินความเสี่ยงฝน <br />
ระบบจะอ่านข้อมูลจากเซนเซอร์ ได้แก่ อุณหภูมิ ความชื้นสัมพัทธ์ และความกดอากาศ จากนั้นนำข้อมูลไปประมวลผลเพื่อแสดงสถานะการประเมินความเสี่ยงฝนบนเว็บไซต์ พร้อมแสดงค่าที่ตรวจวัดได้ผ่านหน้าเว็บไซต์และจอ LCD เพื่อให้ผู้ใช้งานสามารถติดตามสภาพแวดล้อมได้สะดวกยิ่งขึ้น
### **วัตถุประสงค์ของโครงงาน** <br />
- เพื่อพัฒนาระบบตรวจวัดสภาพแวดล้อมด้วย Arduino UNO R4 และเซนเซอร์ BME680 <br />
- เพื่อแสดงข้อมูลอุณหภูมิ ความชื้น และความกดอากาศ <br />
- เพื่อพัฒนาระบบประเมินความเสี่ยงฝนจากข้อมูลที่ตรวจวัดได้ <br />
- เพื่อแสดงข้อมูลและผลการประเมินผ่านเว็บไซต์ <br />
- เพื่อประยุกต์ใช้เทคโนโลยี Physical Computing และ IoT ในการติดตามสภาพแวดล้อม <br />
